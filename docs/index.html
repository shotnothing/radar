The missing layer between people and LLMs.

Users should not have to manually design prompts, agents, workflows, and skills. Radar learns from the work they already do, then brings AI forward only when it has a useful next step.

Passive workflow learning

Observe Chrome and SeaTalk activity while the user works normally, then keep only meaningful action context.

Feedback-weighted memory

When the user accepts a suggestion, that workflow becomes more likely to appear in the same context later.

LLM-made suggestions

The agent turns learned patterns into clear English suggestions instead of exposing prompts, selectors, or logs.

Skills without setup

New work can become a reusable workflow after the user performs it once, without manually building a tool first.

User guide

Use Radar as a quiet side panel that learns your routines and helps when it sees a useful next step.

01

Work normally

Use your usual tools and follow your normal flow. Radar observes the meaningful steps in the background without asking you to set anything up first.

02

Radar learns the pattern

When a routine starts to repeat, Radar filters out noise and turns the useful sequence into reusable workflow knowledge.

03

Get a clear suggestion

The side panel explains the next helpful action in plain English, so you can use AI without stopping to design a prompt or workflow.

04

Choose how much help you want

Keep working on your own, accept the speed-up, or let an agent run the learned workflow when you no longer want to do it manually.

A

Use suggestion

Apply the suggested next step and teach Radar that this workflow is useful in this context.

B

Keep working

Dismiss the suggestion quietly. Radar stays out of the way and keeps learning from your work.

C

Delegate to agent

Let Radar hand the learned workflow to an agent so it can perform the task directly.

Developer guide

Minimal commands for running the demo locally and explaining the technical foundation.

1

Install Python dependencies

Use the repo root and create a local virtual environment for the coordinator and collectors.

Terminalsetup
cd /Users/SIPSS0578/Desktop/Hackathon
python3 -m venv /tmp/radar-venv
/tmp/radar-venv/bin/python -m pip install -r requirements.txt
2

Package and load the Chrome extension

Build the unpacked extension, then load the generated folder in Chrome Developer Mode.

Terminalextension
make PYTHON=/tmp/radar-venv/bin/python package-chrome-extension
open -a "Google Chrome" chrome://extensions
3

Run the coordinator with Chrome collection

The coordinator launches the managed Chrome collector and writes JSONL observations under the debug work folder.

Terminalrun
PATH=/tmp/radar-venv/bin:$PATH \
RADAR_COLLECTOR_META=builtin/collector/chrome/meta.json \
make PYTHON=/tmp/radar-venv/bin/python run-coordinator

Architecture at a glance.

A simple loop that is easy to understand and strong enough to grow into a production system.

Input

Real work

User activity enters through local collectors and controlled app-specific signals.

Filter

Useful signals

Raw UI details become compact events with target, context, and nearby actions.

Match

Workflow patterns

Recent sequences are compared against learned patterns with noise removed.

Explain

LLM suggestion

The expected next action is translated into human-readable English.

Learn

Reusable skill

Accepted actions receive a priority boost and can become reusable workflows.

Radar makes AI proactive, personal, and self-evolving.

The hackathon story is simple: users work once, Radar learns the pattern, the side panel suggests what AI can do next, and accepted suggestions become reusable skills without manual workflow setup.
